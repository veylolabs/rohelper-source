# RoHelper source snapshots

Matching GPL-3.0 source for released RoHelper builds, maintained by Veylo Labs. Application downloads live in [rohelper-releases](https://github.com/veylolabs/rohelper-releases); public game catalogs live in [rohelper-game-data](https://github.com/veylolabs/rohelper-game-data).

## Download matching source

- [RoHelper 0.8.1 source](RoHelper-0.8.1-source.zip)
- [RoHelper 0.9.0 source](RoHelper-0.9.0-source.zip)
- [RoHelper 0.9.1 source](RoHelper-0.9.1-source.zip)
- [RoHelper 0.9.3 source](RoHelper-0.9.3-source.zip)

Each archive contains the full Helper source tree, UI, native implementation, required SDK headers, vendored dependencies, build scripts, tests and license notices for that exact version. See SHA256SUMS.txt for archive checksums. Extract the archive and read Helper/README.md for build instructions.

These are audited source snapshots, not workspace backups. No saved accounts, login sessions, browser profiles, inventories, private app-data files or developer home/workspace paths are included. Required upstream copyright, license and source-attribution notices remain intact.

Source archives are intentionally hosted here rather than attached to app releases. Old source snapshots remain available for matching binaries.
